# Seletor de cursos
Manipulação de elementos DOM com vetores.


Este repositório é um exercício de JS que envolve manipulação de elementos DOM com vetores.

Ainda estou aprendendo sobre a linguagem **JavaScript**, já tenho noções básicas de manipulação dos elementos de um documento **HTML**.

Este exercício consiste em duas seções, uma possui um menu com opções e dois displays, um deles mostra algumas informações, enquanto que o outro mostra o vetor e como ele está sendo manipulado.
A outra seção mostra uma lista com tecnologias, o usuário clica no nome da tecnologia e a bolinha de opções é preenchida, feito isso, o usuário poderá executar uma das ações presentes na primeira seção (Ex: Adicionar, remover, etc.)
